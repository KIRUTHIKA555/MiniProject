E-commerce Sales Analysis Dashboard
Project Overview
This project analyses e-commerce sales data to understand sales performance, profitability, order trends, product performance, and category-wise sales. An interactive Power BI dashboard is created to help users explore the business performance.
Objectives
Track overall sales and profit.
Measure profit margin and average order value.
Understand monthly sales and profit trends.
Compare sales performance across product categories.
Identify products with the highest quantities sold.
Tools & Technologies
Microsoft Excel -- data preparation and initial review
Power Query -- data cleaning and transformation
Microsoft Power BI -- data modelling, DAX measures, and dashboard creation
DAX -- KPI calculations
Dataset
The project uses e-commerce data organised into these tables: - Customers -- customer-related information - Products -- product names and category details - Orders -- order, sales, quantity, and profit details
Update this section if your final dataset uses different table names or columns.
Key Performance Indicators (KPIs)
The dashboard includes: - Total Sales - Total Profit - Profit Margin (%) - Total Orders - Average Order Value (AOV)
Dashboard Features
Monthly sales and profit trend
Sales by product category
Total quantity by product
Date filter to explore a selected period
KPI cards for a quick business overview

Key Business Questions
This dashboard helps answer questions such as: 1. What are the total sales and total profit? 2. What is the overall profit margin? 3. How many orders were received? 4. What is the average order value? 5. Which product categories contribute the most to sales? 6. Which products have the highest quantity sold? 7. How do sales and profit change month by month?
